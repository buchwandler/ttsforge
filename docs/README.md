# TTSForge documentation sources

The documentation is written in Markdown and built with Sphinx and MyST. Start at
[the user guide](index.md), or open the [CLI reference](cli.md),
[project lifecycle](projects.md), [migration guide](migration-readio.md), or
[Python API boundary](api/index.md).

contract and integration checks.
